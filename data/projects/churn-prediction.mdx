## Problem

Businesses lose revenue when customers leave without warning. Spotting the ones at risk *before* they go makes it possible to act — but that means turning raw customer data into a reliable prediction.

## Approach

- Explored and cleaned the dataset with **Pandas**, handling missing values and encoding categorical features.
- Trained and evaluated a classifier with **scikit-learn**, tuning it to balance accuracy against overfitting.
- Wrapped the model in a small **Qt Designer** desktop interface so predictions can be run without touching code.

## Outcome

The model reached **~80% accuracy** at predicting churn, delivered through a simple UI that turns a trained model into something a non-technical user can actually use.

**Tools:** Python · scikit-learn · Pandas · Qt Designer
