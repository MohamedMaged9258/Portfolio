## Problem

A library needs to track books, students, and every borrow and return — reliably, and without corrupting its records or exposing sensitive data.

## Approach

- Designed the system around clean **object-oriented** models for books, members, and loans.
- Built a desktop interface with **Java Swing** for everyday operations.
- Backed everything with a **MySQL** database, using safe, parameterized queries to guard against injection and keep records consistent.

## Outcome

A working management system that handles the full borrow-and-return lifecycle, with data integrity and secure queries treated as first-class concerns rather than afterthoughts.

**Tools:** Java · MySQL · Swing · OOP
